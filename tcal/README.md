# tcal

A GANTT-style terminal UI for [Taskwarrior 3](https://taskwarrior.org/):
see your tasks on a week-by-week timeline and act on them without typing
`task` commands.

Install:

```bash
uv tool install "git+https://github.com/grovesteyn/tchart.git#subdirectory=tcal"
```

The full documentation (installation, filters, views, keys, undo, note
links) is in the repository's main
[README](https://github.com/grovesteyn/tchart#readme).
